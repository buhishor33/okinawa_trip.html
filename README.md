          沖繩自駕 5 天 4 夜・行程規劃網頁  –  README
========================================================================

【專案簡介】
這是一個專為好友自駕旅行設計的互動式行程頁面（HTML），
將繁雜的行程表轉化為清晰、美觀、手機友好的視覺化指南。
所有景點、時間、備註與連結一目了然，方便旅途即時查閱。

【功能特色】
- 每日行程摺疊：點擊日期標題即可展開／收合當天內容，保持版面整潔。
- 深色 / 淺色模式：一鍵切換，適應不同閱讀環境，保護眼睛。
- 內建 Google Maps 導航：每個景點都附有「導航」按鈕，點擊直達地圖。
- Instagram 標籤連結：快速查看該景點的熱門打卡照片，方便拍照取景。
- 同行旅伴標示：清楚顯示成員，並在備註中針對個人需求做細部安排。
- 租車資訊卡片：集中顯示取還車時間、車型、費用與聯絡方式。
- 美食與活動建議：提供當地推薦餐廳與必玩體驗。

【使用方式】
1. 下載 index.html 檔案，或部署至任何靜態網頁空間。
2. 以瀏覽器開啟 index.html 即可使用。
3. 所有外部連結（Google Maps、Instagram）皆可正常運作，需保持網路連線。
4. 行程內容可依實際情況自行修改 HTML 中的文字與連結。
   (小提示：行程已內建摺疊功能，出發前可先全部展開確認細節，旅途當天再收起不必要部分。)

【技術架構】
- HTML5 – 語意化結構，無需外部依賴。
- CSS3 – 自訂變數 (var) 實現主題切換，RWD 響應式設計。
- 原生 JavaScript – 輕量互動（摺疊、深色模式），無需第三方庫。
- Google Fonts – 使用 Noto Sans TC 提升繁體中文閱讀體驗。
